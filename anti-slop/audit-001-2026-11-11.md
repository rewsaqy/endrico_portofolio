# Anti-Slop Audit 001 — Endrico Persona Portfolio (2026-11-11)

Audit menyeluruh proyek existing berdasarkan `antislop` + `antislop-ui` (Mode AFTER).  
Item di bawah ini **belum diubah** pada kode selain komponen pop-up `HeroGeometric` (`src/components/ui/shape-landing-hero.tsx`) dan durasinya di `src/App.tsx`. Balas dengan nomor item yang ingin kamu perbaiki.

> Prioritas mengikuti tier rule `antislop`:  
> **HIGH** = Hard Gate (`R-02`, `R-03`, `R-17`, `R-18`, `R-23`..`R-28`, `R-32`..`R-40`)  
> **MEDIUM** = Purpose-Gate (`R-01`, `R-04`, `R-06`..`R-10`, `R-12`..`R-14`, `R-19`, `R-22`)  
> **LOW** = Quality Locks (`R-05`, `R-11`, `R-15`, `R-16`, `R-20`, `R-21`, `R-29`..`R-31`)

---

1. **[HIGH] [R-02]** `src/pages/HomePage.tsx` (baris 90) — Memakai karakter em dash (`—`) pada teks bio `"3D Artist & Game Designer — fokus pada..."` (wajib diganti koma, titik, atau tanda pisah lain kecuali disetujui pemilik).
2. **[HIGH] [R-39 / R-32]** `src/components/MangaCharacter.tsx` (baris 103), `src/App.tsx` (baris 233), `src/components/YofukashiMusicPlayer.tsx` (baris 111), `src/pages/ProjectsPage.tsx` (baris 126) — Menggunakan `div` dengan `onClick` untuk elemen interaktif (kartu proyek, tombol kembali footer, info track, potret karakter), sehingga tidak dapat dioperasikan via keyboard (`Tab`/`Enter`/`Space`).
3. **[HIGH] [R-39]** `src/pages/ContactPage.tsx` (baris 104–121) — `<label>` `"LEAVE A CALLING NOTE"` tidak memiliki atribut `htmlFor` yang terhubung ke `id` elemen `<input>`.
4. **[HIGH] [R-38 / R-26 / C-5]** `src/pages/ContactPage.tsx` (baris 59 & 16–24) — Tautan email memakai alamat placeholder `mailto:endrico@example.com` tanpa penanda `[REAL DATA]`, dan form `"LEAVE A CALLING NOTE"` hanya menampilkan status `"TRANSMITTED"` lokal selama 4 detik tanpa mengirim data ke backend atau client email.
5. **[HIGH] [R-39 / R-03]** `src/pages/SkillsPage.tsx` (baris 161–200) & `src/components/HeaderNav.tsx` (baris 38–51) — Tab kategori mobile (`3D ART`, `GAME DESIGN`, `PIPELINE`) tidak memakai semantik `role="tablist"`/`role="tab"`/`aria-selected`, serta tinggi tap target tab mobile dan tombol `KEMBALI` masih di bawah minimum 44px.
6. **[HIGH] [R-39]** `src/components/YofukashiMusicPlayer.tsx` (baris 65, 99, 142, 199, 239) — Tombol kontrol ikon-saja (Prev, Next, List, Mute, Close) hanya memakai `title`, belum memiliki `aria-label` dan `aria-hidden="true"` pada ikon SVG di dalamnya.
7. **[HIGH] [R-25]** `src/components/YofukashiMusicPlayer.tsx` (baris 270), `src/components/MangaLoadingScreen.tsx` (baris 151, 254, 261), `src/pages/ProjectsPage.tsx` (baris 95) — Beberapa teks informasi memakai `text-zinc-500` (`#71717a`) di atas hitam (`#000000` / `#09090b`), rasio kontras ~4.3:1 untuk teks kecil di bawah standar minimum WCAG AA 4.5:1.
8. **[HIGH] [R-40]** `src/components/MangaCharacter.tsx` (baris 116) & `src/components/ContentModal.tsx` (baris 60) — Elemen `<img>` karakter utama tidak menyertakan atribut `width`/`height` eksplisit maupun `fetchpriority="high"` pada visual hero di Home.
9. **[HIGH] [R-17 / R-38]** `src/pages/ProjectsPage.tsx` (baris 298, 311, 361, 369, 399) — Panel HUD menampilkan angka spesifik (`140 BPM`, `0ms Audio Drift`, `92% INTEGRITY`, `24.8K QUADS`, `OCT 14, 02:40 AM`); perlu konfirmasi apakah merupakan metrik proyek nyata atau diberi penanda ilustratif.
10. **[HIGH] [R-32]** `src/components/ContentModal.tsx` (baris 10–52) — Modal memiliki penanganan `Escape`, namun belum memindahkan fokus otomatis ke dalam modal maupun menjaga focus-trap saat dibuka.
11. **[HIGH] [R-39]** `src/index.css` & `src/components/MangaCharacter.tsx` (baris 61) & `src/components/MangaLoadingScreen.tsx` — Animasi utilitas bawaan Tailwind seperti `animate-bounce`, `animate-pulse`, `animate-ping`, dan `animate-spin` belum dihentikan di bawah `@media (prefers-reduced-motion: reduce)`.
12. **[MEDIUM] [R-19 / R-09]** `src/pages/ProjectsPage.tsx` (baris 139, 226, 280, 297, 333, 383), `src/components/MangaLoadingScreen.tsx` (baris 137, 148, 215), `src/components/BottomEqualizerBar.tsx` (baris 140), `src/components/YofukashiMusicPlayer.tsx` (baris 276) — Beberapa titik status (`animate-ping`, `animate-pulse`) dan bintang dekoratif (`animate-bounce` di `MangaCharacter.tsx` baris 61) terus berdenyut/memantul tanpa batas sebagai hiasan tanpa menyatakan status real-time.
13. **[MEDIUM] [R-04]** `src/components/MangaLoadingScreen.tsx` (baris 2), `src/pages/ProjectsPage.tsx` (baris 9), `src/pages/AboutPage.tsx` (baris 2) — Ikon `Sparkles` dari `lucide-react` masih terimpor/terpakai pada beberapa bagian yang lebih tepat memakai motif bintang/glyph manga internal atau dihapus jika tidak dipakai.
14. **[MEDIUM] [R-10]** `src/components/ContentModal.tsx` (baris 25) — Memakai `backdrop-blur-md` pada overlay modal padahal estetika Yofukashi noir menggunakan tinta hitam solid dan garis tegas putih.
15. **[LOW] [R-20 / Kualitas Build]** `tsconfig.json` / TypeScript (`npx tsc --noEmit`) — Belum ada deklarasi tipe Vite (`/// <reference types="vite/client" />` di `src/vite-env.d.ts`) sehingga `npx tsc --noEmit` melaporkan error `TS2339: Property 'env' does not exist on type 'ImportMeta'` di 4 file (`ContentModal.tsx`, `MangaCharacter.tsx`, `MangaLoadingScreen.tsx`, `MusicPlayerContext.tsx`).
16. **[LOW] [R-37]** Root proyek — Belum ada file `DESIGN.md` tertulis di root repositori sebagai sumber kebenaran token palet, tipografi, dan dial desain (`ENERGY 3 / RHYTHM 3 / MOTION 2`).
